Fitness & Wellness

A personal fitness and wellness web application focused on making workouts and everyday nutrition easier to plan and follow.

Built with React, JavaScript, and Vite, with a responsive interface designed for both desktop and mobile.

Explore the demo

This interactive preview opens directly in demo mode — no account or sign-in required. It uses sample information and saves demo changes locally in your browser.

What's included

Dashboard — a clear overview of daily activity and wellness goals.

Workout planning — browse workout plans and explore individual exercises.

Workout sessions — follow exercises with visual guides and illustrated exercise avatars.

Nutrition — explore meal plans, recipes, and meal selections.

Responsive layout — designed for desktop and mobile screens.

Some areas, including the Progress Dashboard, AI Coach, and Food Scanner, are marked Coming Soon while they are being developed.

Tech stack

React and JavaScript

Vite

CSS and responsive UI

React Router

Browser local storage for demo data

Run locally

You'll need Node.js and npm installed.

npm ci
npm run dev

Open the local address shown in the terminal.

To create a production build:

npm run build

Project status

This is an ongoing personal project. The public preview demonstrates selected features and the interface; it is not intended as a production fitness or nutrition service.
